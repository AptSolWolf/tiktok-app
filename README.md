# TikTok Content Scheduler

A content scheduling and automation tool for publishing video content to TikTok via the official TikTok Content Posting API.

***

## What This Is

This repository hosts the legal documentation (Terms of Service and Privacy Policy) required for TikTok Developer API registration. It is associated with a content automation tool that enables creators to publish and manage videos on their TikTok accounts.

The tool integrates with TikTok's Content Posting API and operates via:
- **n8n** — a self-hosted workflow automation platform
- **A custom desktop application** — privately developed for content creators

## Usage

This tool is designed for **content creators** managing their own TikTok presence. It is not a public-facing SaaS platform or multi-user application. No third-party user data is collected, stored, or processed.

TikTok API scopes used:
- `video.publish` — to post videos directly to the authorized TikTok account
- `video.upload` — to handle video file transfers to TikTok's servers
- `user.info.basic` — to identify and authenticate the authorized user
