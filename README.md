# TikTok Content App

A personal tool for managing and automating video uploads to a TikTok account via the official TikTok Content Posting API.

***

## What This Is

This repository hosts the legal documentation (Terms of Service and Privacy Policy) required for TikTok Developer API registration. It is associated with a personal content automation tool used to publish videos to a single TikTok account for content creation and channel growth.

The tool integrates with TikTok's Content Posting API and may operate via:
- **n8n** — a self-hosted workflow automation platform
- **A custom desktop application** — privately developed for personal use

## Usage

This app is for **personal use only** by the account owner and developer. It is not a public-facing product, SaaS platform, or multi-user application. No third-party user data is collected, stored, or processed.

The only TikTok API scope used is:
- `video.publish` — to post videos to the authorized TikTok account
